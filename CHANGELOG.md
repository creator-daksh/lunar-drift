# Changelog

## v1.0.0 - Initial Release (2026-09-12)

### Features
- ✨ Animated moon with glowing, pulsing effect
- ✨ Gyroscope parallax control
- ✨ Swipe left/right manual parallax
- ✨ Double-tap pulse animation
- ✨ Motion stability detection (3 seconds)
- ✨ Sensor filtering and smoothing
- ✨ Starfield background
- ✨ Full offline operation
- ✨ Live wallpaper integration

### Technical
- Built with Python 3 + Kivy 2.2.1
- 60 FPS smooth rendering
- Gyroscope + Accelerometer support
- Minimal permissions (BODY_SENSORS only)
- Android 5.0+ support
- Buildozer APK generation

### Permissions
- BODY_SENSORS: Gyroscope/accelerometer
- VIBRATE: Optional, future haptic feedback
- WAKE_LOCK: Live wallpaper rendering
- CHANGE_CONFIGURATION: Orientation handling

### Future
- Customizable settings screen
- Multiple moon phases
- Adjustable animation speed
- User-configurable colors
- Haptic feedback
- Cloud settings sync
